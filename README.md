# 💼 Employee Payroll System

A Python-based Employee Payroll System that calculates employee salaries, allowances, deductions, and generates payroll reports using Object-Oriented Programming (OOP).

## ✨ Features

- 👨‍💼 Employee Record Management
- 💰 Salary Calculation
- ➕ Allowance Processing
- ➖ Deduction Management
- 📊 Payroll Report Generation
- ⚠️ Input Validation & Error Handling
- 🏗️ Object-Oriented Design

---

## 🛠️ Tech Stack

- Python 3
- Object-Oriented Programming (OOP)
- Functions & Dictionaries
- Exception Handling
